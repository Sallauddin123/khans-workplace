# KHAN’s Workplace – Car Workshop Website

A responsive website for a car modification, rebuild, repair, paint and interiors workshop, built with plain HTML, CSS and JavaScript (no frameworks).

## Features
- Live paint colour picker: tap a colour and the car changes colour instantly
- Before and after slider to compare a car's condition
- Service sections: modification, full rebuild, repair and service, paint and body, grafting and welding, seat covers and interior
- Work gallery with demo illustrations (replace with real photos)
- Quote form that opens a ready-to-send WhatsApp message
- Responsive layout (mobile, tablet, desktop) with keyboard-friendly controls

## Tech
HTML5, CSS3 (Grid, Flexbox, CSS variables), vanilla JavaScript, inline SVG graphics.

## Run locally
Download the files and open `index.html` in any browser.

## Publish with GitHub Pages
1. Open the repository **Settings** → **Pages**.
2. Under **Branch**, choose `main` and folder `/ (root)`, then **Save**.
3. After a minute your site is live at `https://<your-username>.github.io/<repo-name>/`.

## Customise
- WhatsApp number: in `index.html`, change `WHATSAPP="910000000000"` (country code, no + or spaces).
- Address, phone and opening hours: edit the footer.
- Photos: replace the SVG scenes in the "Our work" section with `<img src="images/your-photo.jpg" alt="...">`.
